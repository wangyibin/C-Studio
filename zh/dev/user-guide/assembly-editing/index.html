组装编辑¶

编辑会改变什么¶

C-Studio 通过编辑 AGP，调整源序列区间在组装中的位置、顺序和方向。同一源序列 区间可以在组装中出现多次，每次出现都作为一个可单独选择和编辑的拷贝。

接触矩阵、覆盖度、PAF 和 GFA 保留各自的原始坐标，显示时根据编辑后的 AGP 重新映射到组装位置。程序内部使用从 0 开始、左闭右开的区间（0-based half-open）； 导入和导出的 AGP 使用从 1 开始、两端闭合的区间（1-based closed）。

每次编辑都需要由用户发起

证据视图可以帮助定位或预览候选区域。是否拆分、移动、反向或复制序列， 仍需由用户根据证据判断并执行。

先选择，再编辑¶

在热图中按住 Shift 单击或拖动，选择要编辑的对象。也可以从覆盖度、共线性或 GFA 视图中选择。右键单击所选对象即可打开操作菜单，各视图使用同一套组装操作。

下文将由一个或多个 contig 组成的编辑单元称为“组装块（block）”。

可用操作¶

操作 效果
Rename… 检查名称有效后，修改染色体、组装块或 contig 的显示和导出名称
Reverse / rotate selection 反转所选对象的排列顺序，并翻转方向
Copy 在组装中为所选源序列区间添加一个拷贝
Dissolve block 拆开所选组装块，使每个 contig 各自成为一个组装块
Add chr boundaries 在所选 contig 周围增加染色体边界
Remove chr boundaries 移除所选边界中符合条件的染色体边界
Delete gap / join blocks 删除符合条件的 AGP 间隙行（gap），连接相邻组装块，并根据已加载的 GFA 去除重叠
Move to debris 将所选序列移入 debris 对象，保留这些序列
Delete contig… 显示剩余拷贝信息，经确认后从组装中移除所选拷贝

复制完成后，选中状态会转移到本次生成的副本。整条染色体的副本保留染色体选区，可继续按染色体插入、移动或编辑；contig 副本保留 contig 选区。

加载 GFA 后，Delete gap / join blocks（Cmd+J / Ctrl+J）会检查每个 新连接边界的 L 记录。如果存在唯一且方向匹配的连接，并且重叠 CIGAR 仅包含 M/=，程序会从右侧 contig 的显示左端裁去相应长度，修改 AGP 源序列区间， 原始 FASTA 不变。已有连接不会重复裁剪。GFA 中没有这对 contig 的连接时， 仅删除 gap；存在多条匹配连接、方向冲突或不支持的重叠时，本次编辑不执行， 并在 Messages 中显示原因。Undo 会恢复 gap 和源序列区间；Dissolve block 也会恢复已记录的重叠裁剪。

hifiasm 的双向连接可能分别记录两个源 contig 上不同的重叠长度。当 L1 标签与 源序列长度一致、且双向连接唯一时，Join 使用被裁剪 contig 自身记录的重叠长度。 仅移动或反向 contig 后保存不会触发去重；需要选中相邻组装块并执行 Delete gap / join blocks。

拆分 contig 时，先选中它，再把鼠标指针移到热图中该 contig 的对角标注框内部。 出现剪切光标后，单击即可拆分。程序会保护 contig 的两端，靠近端点的点击不会 触发拆分。

移动所选对象时，把鼠标指针移到允许插入的边界。出现插入光标后，单击确认 目标位置。移动和复制调整的是源序列区间在组装中的排列，生物学上的分组和 拷贝数仍需由用户判断。

删除前检查剩余拷贝¶

选择 Delete contig… 后，确认对话框会区分已拆分和未拆分的拷贝，并列出 每个所选源序列区间在删除后还剩多少拷贝。如果某个区间一个拷贝也不剩， 对话框会特别提示，便于确认是否要从组装中完全移除这段序列。

删除会直接从组装中移除所选拷贝，不会将其移入 debris。可以用 Undo 恢复； 如果已保存的历史文件与 AGP 匹配，重新打开项目后仍可通过撤销恢复。

历史、撤销与重做¶

每次编辑都会记录操作前后的组装状态，以及本次操作影响的内容。

  • Cmd+Z / Ctrl+Z 撤销一步；
  • Shift+Cmd+Z / Ctrl+Y 重做一步；
  • 将鼠标指针停在 History 中的一条记录上，可预览编辑前后的状态；
  • 单击 History 中的记录，可跳转到受影响的区域；
  • 右键单击已执行的记录并选择 Undo to here，可一次撤销该记录之后的操作。

加载新项目会替换当前编辑历史。如果所选 AGP 有匹配的历史文件，程序会同时 恢复其中的记录。清空全部数据或重新加载源组装，会清除当前编辑历史。

保存与自动保存¶

手动保存会将当前组装布局写入 AGP，保留仍在组装中的 N/U 间隙记录及其 元数据，也会保留 0、na 等合法的未知方向值。程序同时写入与 AGP 同前缀的 .history.json 历史文件，记录已执行和已撤销的操作。重新打开时，只有历史文件 与已保存的 AGP 匹配，程序才会恢复编辑历史。

加载源 AGP 后，程序不会自动把它设为保存目标。第一次手动保存时，需要选择 文件位置。选定可写的、未压缩的 AGP 保存位置并启用自动保存后，每次编辑约 五秒后，程序会同时写入 AGP 和历史文件。gzip 压缩的 AGP 只作为输入文件， 请先另存为未压缩的 .agp。

Reload assembly… 会丢弃全部编辑，恢复最初加载的源 AGP。请在确认要重新 开始时使用这一操作。其他已加载的证据仍保留在工作区。
