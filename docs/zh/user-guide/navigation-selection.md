# 导航与选择

## 热图导航

| 操作 | 结果 |
| --- | --- |
| 拖动 | 按指针轨迹同时平移 X 和 Y |
| 滚轮 | 使用占主导的带符号滚轮增量沿两轴对角平移 |
| Shift + 滚轮 | 水平平移 |
| Command/Control + Shift + 滚轮 | 垂直平移 |
| Command/Control + 滚轮 | 切换分辨率 |
| 双击 | 以指针为中心放大并吸附到合适分辨率 |
| **Fit** | 恢复全组装视口 |

用 **L** 锁定分辨率后，Command/Control + 滚轮会以指针为中心缩放视口，而不再
切换所选矩阵层级。

热图会铺满可用绘图区，X、Y 两轴保持相同的基因组长度/像素比例。宽窗口横向显示
更多序列，窄高窗口纵向显示更多序列；调整窗口大小不会拉伸矩阵格子。超出组装末端
的区域保留空白，放大后可查看更小的有效区间。

两条轴上的全基因组导航器也可以独立移动单条轴。拖动 X 或 Y 染色体条时，热图
实时跟随，新瓦片到达一块就显示一块，无需松开鼠标或等待整个视野加载完成。
松手确认当前位置。平移位置受组装范围限制。

新区域加载期间，已有热图会继续跟随指针移动。刚进入视野的区域可能短暂留白，
数据到达后会自动补齐；这类临时空白不表示该区域没有接触信号。

Coverage 轨道也在拖动热图、拖动 X 染色体条或滚轮平移时实时跟随 X 视野，
包括柱形、染色体边界和选中区域。新区域的数据在加载后自动补入，无需松手。
平移期间深度纵轴保持稳定；只移动 Y 视野时，coverage 的 X 位置不变。

Overview 热图中的视野框也随热图拖动、X/Y 染色体条拖动和滚轮平移实时移动，
无需松手。取消拖动时，视野框与主热图一起返回原位置。

切换分辨率或归一化时，保留当前画面直到新画面就绪，再切到新视野。

## 跳转到区域

X 和 Y **Jump** 输入框接受：

```text
contig_name
contig_name:start-end
```

输入区间按源 contig 坐标解释。如果一条轴留空，另一条轴的输入会同时用于两轴。
C-Studio 会把视口移到中心并选中对应放置 block。contig 名称有歧义或不存在时会
报错，不会静默选择其中一个。

## 从热图选择

普通拖动保留给平移；按住 Shift 与组装叠加框交互：

- Shift 单击 contig：替换当前选择；
- Shift 单击染色体边界：选择整条染色体；
- Shift 单击空白：清除选择；
- Shift 框选：选择所有相交 contig。

选中区间会同时投影成横向和纵向阴影。拖动选择边界手柄，可在 contig 边界处扩大
或缩小所选集合。

## 从同步证据中选择

覆盖度和交互式共线性视图共享热图 X 轴视口：

- 单击替换当前 contig 选择；
- Command/Control 单击切换单个 contig；
- Shift 拖动选择多个 contig；
- 双击在指针处放大；
- 拖动图中空白区域平移共享 X 区域。

在 GFA 面板中，Shift 拖动可选择多个 AGP block，右键打开同一组装操作菜单，
滚轮缩放图画布。移动图布局只改变图的绘制位置，除非用户明确确认组装操作。

## 清除或取消

按 ++esc++ 清除当前组装选择或取消正在进行的上下文交互。在输入框、文本区、
下拉框或可编辑控件中输入时，应用级快捷键会被忽略。
