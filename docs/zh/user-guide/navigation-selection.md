# 导航与选择

## 热图导航

| 操作 | 结果 |
| --- | --- |
| 拖动 | 按指针轨迹同时平移 X 和 Y |
| 滚轮 | 使用占主导的带符号滚轮增量沿两轴对角平移 |
| Shift + 滚轮 | 水平平移 |
| Command/Control + Shift + 滚轮 | 垂直平移 |
| Command/Control + 滚轮 | 切换分辨率 |
| 双击 | 以指针为中心放大并吸附到合适分辨率 |
| **Fit** | 恢复全组装视口 |

用 **L** 锁定分辨率后，Command/Control + 滚轮会以指针为中心缩放视口，而不再
切换所选矩阵层级。

两条轴上的全基因组导航器也可以独立移动单条轴。所有视口变化都会被限制在组装
范围内。

## 跳转到区域

X 和 Y **Jump** 输入框接受：

```text
contig_name
contig_name:start-end
```

输入区间按源 contig 坐标解释。如果一条轴留空，另一条轴的输入会同时用于两轴。
C-Studio 会把视口移到中心并选中对应放置 block。contig 名称有歧义或不存在时会
报错，不会静默选择其中一个。

## 从热图选择

普通拖动保留给平移；按住 Shift 与组装叠加框交互：

- Shift 单击 contig：替换当前选择；
- Shift 单击染色体边界：选择整条染色体；
- Shift 单击空白：清除选择；
- Shift 框选：选择所有相交 contig。

选中区间会同时投影成横向和纵向阴影。拖动选择边界手柄，可在 contig 边界处扩大
或缩小所选集合。

## 从同步证据中选择

覆盖度和交互式共线性视图共享热图 X 轴视口：

- 单击替换当前 contig 选择；
- Command/Control 单击切换单个 contig；
- Shift 拖动选择多个 contig；
- 双击在指针处放大；
- 拖动图中空白区域平移共享 X 区域。

在 GFA 面板中，Shift 拖动可选择多个 AGP block，右键打开同一组装操作菜单，
滚轮缩放图画布。移动图布局只改变图的绘制位置，除非用户明确确认组装操作。

## 清除或取消

按 ++esc++ 清除当前组装选择或取消正在进行的上下文交互。在输入框、文本区、
下拉框或可编辑控件中输入时，应用级快捷键会被忽略。
