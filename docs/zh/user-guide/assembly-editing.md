# 组装编辑

## 编辑模型

C-Studio 编辑当前 AGP 放置列表。内部区间使用 0-based half-open，导入和导出的
AGP 坐标使用 1-based closed。接触矩阵、覆盖度、PAF 和 GFA 保留各自原始坐标系，
并通过编辑后的放置关系重新投影。

!!! important

    每次编辑都由用户发起。证据视图可以定位或预览候选，但不会替用户选择
    生物学操作。

## 先选择，再编辑

可在热图中使用 Shift 单击或 Shift 拖动，也可从覆盖度、共线性或 GFA 中选择。
右键所选对象打开共享操作菜单。

## 可用操作

| 操作 | 效果 |
| --- | --- |
| **Rename…** | 验证后修改染色体、block 或 contig 的显示/导出名称 |
| **Reverse / rotate selection** | 反转所选顺序并翻转方向 |
| **Copy** | 为所选源区间创建另一个放置 |
| **Dissolve block** | 将所选复合 block 拆成单 contig block |
| **Add chr boundaries** | 在所选 contig 周围增加染色体边界 |
| **Remove chr boundaries** | 移除符合条件的所选染色体边界 |
| **Delete gap / join blocks** | 删除符合条件的 AGP gap 行并连接相邻 block |
| **Move to debris** | 把所选序列保留到 debris 对象中 |
| **Delete contig…** | 经拷贝感知确认后移除所选放置 |

拆分 contig 时，先选中它，再把指针移到其对角框内部。当出现剪切光标时单击。
端部区域有保护，靠近端点的点击不会被当作剪切。

移动所选对象时，把指针移到有效插入边界，出现插入光标后单击确认目标。移动与
复制操作针对放置关系，不代表程序作出了生物学分组或拷贝数判断。

## 感知拷贝的删除

**Delete contig…** 会打开确认对话框，区分拆分和未拆分拷贝，并报告每个所选源
区间还剩多少拷贝。如果删除后一个拷贝都不剩，会明确突出这一损失。

删除会从组装中移除放置，而不是移动到 debris。当前会话内可以用 Undo 恢复。

## 历史、撤销与重做

每个 reducer 编辑都会记录操作前后组装状态和影响摘要。

- ++cmd+z++ / ++ctrl+z++ 撤销一步；
- ++shift+cmd+z++ / ++ctrl+y++ 重做一步；
- 悬停 History 条目可预览前后状态；
- 单击 History 条目可定位受影响区域；
- 右键已应用条目并选择 **Undo to here**，可一次回退其后的操作。

加载新项目、清空全部数据或重新加载源组装都会清除编辑历史。

## 保存与自动保存

手动保存会把当前规范布局写成 AGP，同时保留尚存在的 `N`/`U` gap 元数据以及
`0`、`na` 等合法未知方向。

已知可写普通 AGP 路径时，自动保存会在变更约五秒后写入。因此项目目录中的
`.agp` 可能被覆盖。gzip AGP 只能作为只读输入目标；请先另存为普通 `.agp`。

只有在确实要丢弃全部编辑并恢复最初加载的源 AGP 时，才使用
**Reload assembly…**。其他已加载证据仍保留在工作区。
