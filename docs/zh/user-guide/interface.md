# 界面说明

## 全局工具栏

顶部第一行包含整个项目级的操作：

- 当前 AGP 名称与 **Auto-save** 设置；
- 用于加载项目目录和单项证据的 **Add Data**；
- 用于 GFA 同源分组排列的全局 **Homolog regex**；
- 在不修改 AGP 的前提下，同步过滤热图、共线性、覆盖度和 GFA 视图的
  **Chromosomes** 显示过滤器；
- 撤销、重做、保存/另存 AGP、显示/隐藏检查器和应用信息。

保存时会同时写入编辑后的 AGP 及其同前缀操作历史 sidecar。

信息菜单还会显示当前键盘快捷键及核心使用的坐标约定。

## 热图工具栏

第二行控制接触矩阵视图：

- 分辨率滑块与分辨率锁定；
- 颜色最小值、最大值和 **Auto** 范围；
- 接触矩阵归一化；
- 染色体、复合 block 和 contig 标注可见性；
- 全组装 **Fit** 与 X/Y 区域 **Jump**。

对于 `.mcool`，分辨率滑块使用文件中实际存储的金字塔层级。其他视图的可用
层级由当前视口和支持的显示分辨率共同限制。

## 中央工作区

热图是主要工作区，可以显示：

- 按当前 AGP 布局投影的接触矩阵 tile；
- 染色体、复合 block 与 contig 叠加框；
- 同时投影到矩阵两条轴的选择阴影；
- 矩阵下方的覆盖度轨道；
- 可选的并排共线性面板；
- 可选且可调整高度的 GFA 图面板。

热图与证据窗口可以关闭或展开；关闭窗口不会卸载对应数据源。

## 检查器

右侧检查器可调整宽度，也可用 ++f9++ 隐藏，其中包含：

- **Overview**：全组装接触矩阵概览；
- **Synteny**：紧凑 PAF 视图；双击打开交互式分屏；
- **GFA**：紧凑组装图预览；双击打开图面板；
- **Selection**：所选染色体、block、contig 和拷贝信息；
- **History**：已应用和已撤销操作；
- **Project Info** 与导出就绪状态。

鼠标悬停或键盘聚焦历史条目时会预览受影响区域，单击会定位到该区域。右键已应用
的历史条目可选择 **Undo to here**。

## 状态栏

底部状态栏显示分辨率、归一化、矩阵、组装、当前工具、X/Y 中心和最新状态消息。
只有明确启用性能日志后才会出现诊断计时文本。
