# 键盘快捷键

焦点位于输入框、文本区、下拉框或可编辑元素时，应用级快捷键会被禁用。

## 项目与历史

| 操作 | macOS | Windows/Linux 标签 |
| --- | --- | --- |
| 保存 AGP | ++cmd+s++ | ++ctrl+s++ |
| 撤销 | ++cmd+z++ | ++ctrl+z++ |
| 重做 | ++shift+cmd+z++ | ++ctrl+y++ |
| 撤销备用快捷键 | ++cmd+u++ | ++ctrl+u++ |
| 重做备用快捷键 | ++cmd+r++ | ++ctrl+r++ |
| 取消选择/取消操作 | ++esc++ | ++esc++ |
| 显示/隐藏标注 | ++f2++ | ++f2++ |
| 显示/隐藏检查器 | ++f9++ | ++f9++ |
| 打开数据菜单 | ++f10++ | ++f10++ |

## 组装操作

| 操作 | macOS | Windows/Linux 标签 |
| --- | --- | --- |
| 重命名 | ++cmd+e++ | ++ctrl+e++ |
| 反转/旋转 | ++shift+cmd+r++ | ++ctrl+shift+r++ |
| 复制 | ++cmd+d++ | ++ctrl+d++ |
| 移动到 debris | ++shift+cmd+d++ | ++ctrl+shift+d++ |
| 删除 gap/连接 | ++cmd+j++ | ++ctrl+j++ |
| 删除 contig | ++shift+backspace++ | ++shift+delete++ |

这些操作需要符合条件的组装选择。删除 contig 会先打开确认对话框，而不是立即执行。

## 热图滚轮手势

| 操作 | macOS | Windows/Linux 标签 |
| --- | --- | --- |
| 对角平移 | 滚轮 | 滚轮 |
| 水平平移 | Shift + 滚轮 | Shift + 滚轮 |
| 垂直平移 | Command + Shift + 滚轮 | Control + Shift + 滚轮 |
| 切换分辨率 | Command + 滚轮 | Control + 滚轮 |
| 锁定/解锁分辨率 | ++l++ | ++l++ |

分辨率锁定后，原分辨率切换手势会以指针为中心缩放，同时保留当前矩阵层级。
