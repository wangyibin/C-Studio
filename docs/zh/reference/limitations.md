# 当前限制

本页记录解读、分发和验证当前实现时需要注意的边界。C-Studio 仍在积极开发中，
这些内容会随实现与平台验证进展更新。

## 分发与平台

- 桌面应用打包流程面向 Apple Silicon macOS 和 Windows x86-64。它可以生成可复现的
  构建产物，但这本身不代表已建立稳定、带签名的公开发行版。
- macOS 安装包使用临时签名，尚未进行 Apple Developer ID 公证。
- Windows NSIS 与 MSI 安装包未签名，可能触发 SmartScreen。
- 原生文件和目录选择器支持 macOS 与 Windows；但真实 Windows 桌面的完整点击流程和
  WebView2 交互验证仍是独立的发布 QA 工作。
- 尚未提供 Linux 桌面应用的打包或发布 QA 流程。打包工作流中的 Linux 产物属于独立的
  `cool2mcool` 转换工具，而非 C-Studio 桌面应用。

## 示例数据

**Load example project** 会从源码检出目录的 `examples/` 读取文件。这些文件没有声明为
Tauri bundle resource，因此尚未证明该辅助功能可在安装包中使用。请从源码检出运行，
或逐个加载示例文件。

## 导出

- 保存会写入编辑后的 AGP，以及同前缀的 C-Studio `.history.json` sidecar。AGP 可独立
  使用，但其他组装工具不会读取该 sidecar。
- 格式错误或与当前布局不匹配的历史 sidecar 会被忽略；AGP 仍能加载，但不会恢复其
  撤销/重做时间线。
- 自动保存需要用户先选择一个可写的保存目标。压缩的 `.agp.gz` 源文件不能被自动覆盖。
- 检查器中的 FASTA **Ready** 只表示数据集已加载；当前用户界面尚未提供 FASTA 导出。

## 科学解释

- 当前编辑的 AGP 布局仍是排序、方向、边界和导出的权威来源。接触矩阵、PAF、覆盖度和
  GFA 是同步的证据视图，不会静默改写布局。
- 证据引导的放置推荐仅用于复核。应用改动仍需用户确认，且不等同于已完成生物学纠正。
- C-Studio 不会自动判定断点、方向、分组、染色体名称或拷贝数。
- 自动化测试通过并不验证真实生物数据上的编辑后组装；
- 完整校订仍需使用独立的连续性、拷贝数、共线性、接触矩阵和序列层面验证。

## 性能证据

大型单分辨率 `.cool` 文件在每次切换尺度时都可能需要昂贵的投影和聚合。日常多尺度
浏览宜优先使用带有预存分辨率的 `.mcool`。后端或自动化计时不能证明桌面可见的交互
延迟：IPC、前端处理、GPU 呈现和平台 WebView 是不同阶段。性能结论应基于目标桌面
工作流的实测结果。

## GFA 解析范围

当前证据解析器识别 `S`、`L` 和 `A` 记录。只有明确有效的 `L` 记录会创建图边；
`A` 记录计数和 `rd` 标签仍是 segment 元数据，不会被当作边支持。
