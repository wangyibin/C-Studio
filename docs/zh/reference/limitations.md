# 当前限制

本页记录当前 `0.3.5` 检出版本的边界。相应实现或验证状态变化时，应同步更新本页。

## 分发与平台

- macOS 安装包使用临时签名，没有 Apple Developer ID 公证；
- Windows 安装包没有正式签名，可能触发 SmartScreen；
- 项目目录、接触矩阵、PAF 和覆盖度选择已改用 Tauri 跨平台对话框插件；真实
  Windows 桌面的完整点击测试仍属于发布前独立 QA；
- 当前尚未配置 Linux 安装包；
- 仅凭此检出版本，不能证明已建立稳定公开发布、归档源码/测试数据 URL 或引用记录。

## 示例数据

**Load example project** 使用构建时源码检出路径解析文件。示例文件没有声明为
Tauri bundle resource，因此尚未证明安装包内可以成功使用。

## 导出

编辑后 AGP 保存已经实现。加载数据集时，检查器可能把 FASTA 显示为 “Ready”，
但当前用户界面没有提供 FASTA 导出操作。不能把该就绪标签当成已经完成的 FASTA
导出流程。

操作历史持久化使用 C-Studio 专用 `.history.json` sidecar。AGP 仍可独立使用，
但其他组装工具不会读取该 sidecar。

## 科学解释

- C-Studio 不会自动决定断点、方向、分组、染色体命名或拷贝数；
- GFA 与接触证据的 review 候选只是证据提示，不是生物学判定；
- 单元测试通过不能验证真实生物数据上的编辑后组装；
- 完整校订仍需使用独立的连续性、拷贝数、共线性、接触矩阵和序列层面验证。

## 性能证据

大型普通 `.cool` 可能明显慢于带已存分辨率的 `.mcool`。后端基准不能单独证明
桌面交互延迟，IPC、前端合并和 GPU 绘制仍是不同阶段。常规多尺度工作尽量使用
`.mcool`，任何性能结论都应测量真实桌面链路。

## GFA 解析范围

当前证据解析器识别 `S`、`L` 和 `A` 记录。只有明确有效的 `L` 记录会创建图边；
`A` 记录计数和 `rd` 标签仍是 segment 元数据，不会被当作边支持。
