# 当前限制

C-Studio 仍在积极开发中，使用时请注意：

- 桌面安装包仅支持 Apple Silicon macOS 和 Windows x86-64；macOS 安装包未公证，
  Windows 安装包未签名，暂不提供 Linux 桌面版。
- **Load example project** 需要从源码检出运行；安装包中请逐个加载示例文件。
- C-Studio 可以导出编辑后的 AGP 及可选的历史 sidecar，暂不支持 FASTA 导出。
- 当前编辑的 AGP 是权威布局。接触矩阵、PAF、覆盖度和 GFA 只用于辅助复核；每项编辑
  都需用户确认，且仍须通过独立生物学分析验证。
