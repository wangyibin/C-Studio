# Keyboard shortcuts

Application shortcuts are disabled while focus is in an input, text area,
select box, or editable element.

## Project and history

| Action | macOS | Windows/Linux label |
| --- | --- | --- |
| Save AGP | ++cmd+s++ | ++ctrl+s++ |
| Undo | ++cmd+z++ | ++ctrl+z++ |
| Redo | ++shift+cmd+z++ | ++ctrl+y++ |
| Juicebox-style undo | ++cmd+u++ | ++ctrl+u++ |
| Juicebox-style redo | ++cmd+r++ | ++ctrl+r++ |
| Deselect/cancel | ++esc++ | ++esc++ |
| Toggle annotations | ++f2++ | ++f2++ |
| Toggle inspector | ++f9++ | ++f9++ |
| Open data menu | ++f10++ | ++f10++ |

## Assembly operations

| Action | macOS | Windows/Linux label |
| --- | --- | --- |
| Rename | ++cmd+e++ | ++ctrl+e++ |
| Reverse / rotate | ++shift+cmd+r++ | ++ctrl+shift+r++ |
| Copy | ++cmd+d++ | ++ctrl+d++ |
| Move to debris | ++shift+cmd+d++ | ++ctrl+shift+d++ |
| Delete gap / join | ++cmd+j++ | ++ctrl+j++ |
| Delete contig | ++shift+backspace++ | ++shift+delete++ |

Operations require an eligible assembly selection. Delete contig opens a
confirmation dialog rather than deleting immediately.

## Heatmap wheel gestures

| Action | macOS | Windows/Linux label |
| --- | --- | --- |
| Pan diagonally | Scroll | Scroll |
| Pan horizontally | Shift + scroll | Shift + scroll |
| Pan vertically | Command + Shift + scroll | Control + Shift + scroll |
| Switch resolution | Command + scroll | Control + scroll |
| Lock/unlock resolution | ++l++ | ++l++ |

With resolution locked, the resolution gesture zooms around the pointer while
retaining the current matrix level.
